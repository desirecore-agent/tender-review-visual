# Full-raster ROI coverage audit

This companion to `measure_regions.py` checks whether the **same decoded RGB/HSV mask** has pixels outside a chosen ROI. It does not recognize objects, count semantic items, infer chart values or make tender decisions. It adds no package: use the already installed, hash-locked Pillow 12.3.0 / Python >=3.10 environment. Install `scripts/audit_roi_coverage.py` beside the existing reviewed `scripts/measure_regions.py`; the latter supplies the original seven-field validation and limits and is not changed.

Read the input/output Draft-07 schemas. Run this environment's interpreter with the script path and the exact seven-field measurement JSON on stdin. Save the request, complete stdout, stderr and real exit status in separate files under this Agent's current registered private workspace. No unregistered temporary directory or published source writes. The CLI supervises its own spawned worker; the caller should additionally allow a 24-second execution timeout. Exit 0 / `audited` means the mask audit finished; exit 2 / `rejected` means `coverage=unknown`, with no invented partial counts. Do not bypass the supervised CLI by calling its internal Python functions in production.

The output gives exact source SHA-256/bytes, dimensions/format, configuration, total scanned pixels, and full-image/inside-ROI/outside-ROI matched pixel counts and bounding boxes. Boxes use the same unrotated top-left coordinate system, with right/bottom exclusive. No resize or sampling occurs. `min_area` and `connectivity` remain in the request for compatibility, but **do not filter coverage pixels** and no components are computed. The original component helper's 1-million-pixel ROI and 5,000-component limits are not enlarged.

Use the audit before using a local ROI to support a whole-figure geometric statement:

1. Actually view the exact authorized image. For PDF pages, use the verified Read→ExportMedia→local Read chain; preserve the original PDF hash/physical page mapping and exported image identity. Match audit source SHA/bytes to that chain and later region measurement; same path alone is insufficient.
2. Audit the proposed ROI with the same RGB bounds and HSV saturation used for measurement. RGB bounds are inclusive; S=(maxRGB-minRGB)/maxRGB, black S=0. No ICC/gamma transformation is applied.
3. If outside matches exist, locate their reported bounding range in the actual image. They may be omitted objects, axes, labels or background. Record which visible objects are inside/outside the ROI and why. Expand or explicitly tile ROIs as needed within the original 1MP limit, then measure and reconcile object identities across overlap/boundaries. Do not double-count split or overlapping objects. Preserve configurations and all audit results.
4. No outside matches means only that **this threshold** selected no outside pixels. Different colors, weak saturation, holes, crop boundaries and unselected objects still require visual examination. Neither outside=0 nor a connected-region count proves whole-figure completeness. Unexplained disagreement remains unknown/incomplete in the planned denominator; never silently clear it.
5. Any effective transparency anywhere in the full image rejects this audit, including RGB/L PNG tRNS. This is deliberately stricter than the original ROI-only helper, which can measure a fully opaque ROI even when transparency exists elsewhere. Such a local result does not establish full-image coverage. Do not composite or change the original image to manufacture a passing audit; document the limitation and use independently justified visual/manual evidence.

Resource limits: one read-only regular source snapshot, 32 MiB, 16 million whole-image pixels, original ROI at most 1 million pixels, 16 KiB request. Scan checks a 12-second elapsed deadline every 4096 pixels. A separate spawned process also receives at most 18 seconds of parent waiting, with at most two further one-second cleanup joins; native decoder stalls therefore produce rejected/unknown. Startup/scheduling overhead is outside that wait, so a 24-second caller bound remains useful. Pixel storage is bounded by the input/decoded-image caps: a finite number of Pillow raster buffers and constant-size count/bbox accumulators; no per-pixel Python objects or unbounded component lists are retained. These are algorithmic bounds, not a portable OS RSS quota. An OS-killed worker is unknown, not outside=0.

Source files are never written. The final path component is protected with O_NOFOLLOW where available; parent symlinks follow the caller's authorized path resolution. The helper is not an authorization service and does not scan directories, access network, or acquire credentials. A timeout may return null source identity when the worker could not finish reporting it; never attach that failure to a different image by assumption.
