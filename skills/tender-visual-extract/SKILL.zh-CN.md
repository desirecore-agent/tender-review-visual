## 适用场景

- 从 DOCX 文件中安全提取段落文本、表格（含行列定位）、嵌入图片及其关系引用
- 对 PDF 进行能力检查与页图查看（未知安装须先 ToolCatalog + 真实无敏感 smoke 验证）
- 对提取出的图片执行实际查看并记录证据

## 核心原则

1. **图片只证明可见内容**：看到什么记什么，看不到就记看不到。
2. **模糊/缺页/读取失败 ≠ "没有提供" 或 "检查通过"**：一律记为未完成并标注原因。
3. **不鉴定章签/证书真伪**：视觉检查只报告可见性（有/无/模糊），不证明真实有效。
4. **图像与文本矛盾并列保留**：不自行选择"以哪个为准"。
5. **图片必须实际 Read 后才算看过**：未执行 Read 工具的图片不得声称已查看。
6. **部分提取不声称完整成功**：状态为 `partial`/`rejected` 时必须如实汇报未完成项。
7. **DOCX 提取不等于完整 Office 渲染**：`extract_docx.py` 仅提取正文段落、表格与绘图引用的嵌图；页眉、页脚、脚注、尾注、批注、嵌入式 OLE 对象等不在覆盖范围。
8. **云模型通道声明**：使用用户选定的云模型时，发送的文本与图片会由该模型通道处理；不能承诺全程本地处理。
9. **禁止未授权外传**：默认不将标书内容（含提取图、人员信息、报价）发送至 OCR 服务、邮件或陌生 URL；与用户选定云模型的正常文本/图像处理通道须区分。

## DOCX 提取用法

脚本路径（相对于本技能目录）：`scripts/extract_docx.py`

### 基本命令

```bash
python3 <skill_dir>/scripts/extract_docx.py INPUT.docx --out-dir OUTPUT_DIR
```

**建议每次运行使用全新输出目录**。脚本绝不覆盖：本批输出目标路径已存在任何文件/符号链接即拒绝（退出码 5）；目录中无关的既有文件不受影响（只拒绝同名碰撞）。

### 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--out-dir` | （必填） | 提取图片的输出目录。输出目录**本身**为符号链接会被拒绝；父级目录为符号链接时按调用者显式给出路径的 realpath 接受（不承诺拒绝父级链接）。非空目录可接受：只拒绝与本批输出同名的文件/链接碰撞，无关既有文件不触碰（建议每批用全新空目录以获得干净隔离） |
| `--json` | `OUT_DIR/extraction.json` | JSON 结果输出路径（不得指向输入文件） |
| `--max-total-bytes` | 200000000 | ZIP 解压总量上限（防 ZIP 炸弹） |
| `--max-entry-bytes` | 50000000 | 单条目解压上限 |
| `--max-entries` | 2000 | ZIP 条目数上限 |
| `--max-image-bytes` | 100000000 | 图片提取总预算 |
| `--strict` | 关闭 | 遇到任何危险条目即整体中止（安全规则始终执行；此参数仅决定是"拒绝该条目继续"还是"立即中止"） |
| `--min-image-side` | 10 | 尺寸门（**必须大于**语义）：宽或高 ≤ 该值的图标记 `readability=too_small`。默认 10 = 最小可接受尺寸为 11，对齐已确认模型边界（宽高必须 >10）。参数必须 ≥1，0/负数会被拒绝（退出码 64） |

### 输出结构（JSON）

- `status`：`complete`（所有正文引用图像均解析成功或无引用，且无未覆盖容器）/ `partial`（部分解析、部分未完成，或存在未覆盖容器/超限包装深度）/ `rejected`（有引用但无一解析且无外链与未覆盖容器）
- `paragraphs[]`：`paragraph_index` + `text` + `location`（逻辑路径）+ `drawing_relationship_ids`（rid 列表，兼容字段）+ `drawing_references`（含 `rid` 与 `kind`：embed / link / none）
- `tables[]`：`table_index` + `location` + `rows[][]`（仅直属行/直属格文本；嵌套表另立条目并以父格路径关联）
- `images[]`：权威图像清单，以**正文实际 drawing/blip 引用**为分母，**embed 与 link 两种引用种类均计入**（blip 两者皆缺也记一条 `none`，分母不因属性缺失而缩小）。每条含 `relationship_id`、`reference_kind`、`status`（resolved / missing-part / rejected / external-not-fetched / budget-exceeded / unsupported）、`location`（引用处逻辑路径）、`note`（未完成原因）；仅 `resolved` 条目含 `extracted_to`、`sha256`、`dimensions`、`readability`。外链图一律 `external-not-fetched`：只记录、绝不联网、绝不发起请求
- `uncovered_containers[]`：正文中暂不支持的可见容器或超过支持深度的包装结构（未覆盖，不是"没有内容"），每条含 `tag`、`location`、`note`；非空时结果必为 `partial`、退出码非零
- `uncovered_parts[]`：包内存在但本工具不提取的 part（如页眉/页脚/脚注/尾注/批注）
- `security.external_relationships`：外部关系只记录、不跟随
- `security.rejected_entries`：被拒绝的危险 ZIP 条目（含原因）

### 位置语义（重要）

- 所有位置均为**逻辑位置**，不是 Word 页码。DOCX 没有固定分页，**不编造页码**。
- `location` 路径文法：`body:N`（body 第 N 个直接子节点）、`body:N/sdt:M`（内容控件内）、`body:N/row:R/cell:C/para`（表格单元格内段落）。被 `w:sdt` 包装的行/格在路径中带 `/sdt` 段（如 `.../row:R/sdt/cell:C`、`.../cell:C/sdt`），表示该结构由包装节点承载。
- `cell_index` 是行内直属格的**逻辑序号**，不是可见列号（不解释 gridSpan/vMerge 合并格）。`row:R` 中的 R 是逻辑行号，不是 Word 物理页码或可见列位置。

### 覆盖范围声明（不泛称完整 DOCX 审查）

- **已覆盖**：`word/document.xml` 正文（段落、表格、内容控件 `w:sdt` 的有界深度嵌套——含正文多级 sdt、格内嵌套 sdt、格内 sdt 包表、sdt 包行/包格、嵌套表格、绘图引用）+ `word/_rels/document.xml.rels`。超过支持深度（默认 8 层包装）或遇未支持可见容器时，记入 `uncovered_containers` 并返回 partial/非零退出，绝不静默漏掉。
- **未覆盖**：页眉（header）、页脚（footer）、脚注、尾注、批注及其他 story part。包内存在时记入 `uncovered_parts`，不提取、不当作"没有内容"。

### 退出码

| 码 | 含义 |
|----|------|
| 0 | 完整成功（所有引用图像均解析或无图像引用，且无未覆盖容器） |
| 1 | 部分提取（`status=partial`/`rejected`，无预算因素）；JSON 已写出，未完成项如实列出 |
| 2 | 非有效 ZIP/DOCX |
| 3 | 安全违规（路径穿越/符号链接/实体攻击/重复 part/重复关系 Id/炸弹限制） |
| 4 | 缺少必要 document part |
| 5 | 预算超限、输出冲突（目标已存在/指向输入）或写入错误 |
| 64 | 用法/参数错误（含 `--min-image-side` 非法值） |

### 覆盖策略（绝不静默覆盖）

- 脚本**绝不覆盖**任何已存在的文件：图像与 JSON 均以 `O_CREAT|O_EXCL` 排他创建。
- 输出前预校验输入与全部输出的身份与碰撞：规范路径（realpath）+ device/inode 双重比较，不只比较字符串。
- 路径策略与实际行为一致：接受调用者显式给出路径的 realpath 作为写入目标，**不承诺拒绝父级目录的符号链接**（输出目录**本身**是符号链接则拒绝）；非空输出目录可接受，**只拒绝与本批输出同名的文件/链接碰撞**，无关既有文件不触碰、不删除、不覆盖。
- 拒绝：JSON 路径指向输入文件（同路径或同 inode）、输出目录本身为符号链接、输出目录内已有同名文件/链接、图像路径与 JSON 路径互相碰撞。
- 重跑同一输出目录若与本批文件名碰撞会被拒绝（退出码 5）；建议每批用全新目录。

### 安全防护清单

- ZIP 路径穿越（`..`、绝对路径、反斜杠）→ 拒绝
- 符号链接条目 → 拒绝（默认模式：该条目入 `rejected_entries` 且**绝不读取/输出其内容**；必需 part 被拒则整体失败）
- 外部关系（TargetMode=External）→ 只记录不跟随
- XML 实体扩展攻击（DOCTYPE/ENTITY）→ 解析层拒绝，**编码感知**：先按 BOM / NUL 字节启发式 / XML 声明识别并解码（支持 UTF-8、UTF-16LE/BE），在解码后的文本上一致检查；不支持或矛盾的编码声明直接拒绝。所有 document/rels part 共用同一策略
- 重复 canonical part 名（如两份 `word/document.xml`）→ 解析前拒绝；重复关系 Id → 拒绝
- ZIP 炸弹（总量/单文件/条目数）→ 可参数化限制
- 原件只读 + 输出隔离：脚本绝不写入输入文件，输出排他创建

## PDF 读取与能力说明

详见 `pdf-capability-check.zh-CN.md`（相对于本技能目录）。

> **注意**：以下能力基于当前开发环境 smoke test 验证。未知安装/平台必须先 ToolCatalog 读取工具参数 + 真实无敏感 smoke PDF 验证，不得宣称"旧正式版均支持"。

### 两种 Read 模式

| 模式 | 调用方式 | 返回内容 | 适用场景 |
|------|----------|----------|----------|
| **默认（auto）** | `Read(file_path, pages="1")` 或不带 pages 连续读 | 文字页→纯文本；扫描页/图像页→自动渲染为页图；不带 pages 时按预算自动续读 | 快速文本提取、目录扫描、连续阅读 |
| **显式页图（render）** | `Read(file_path, pages="1", pdf_mode="render")` | 所有选页渲染为位图 | 查看配图、签章、图表、版式、嵌入像素徽标 |

### 行为要点

- `render` **必须**显式提供有效 `pages`，不能与 `outline=true` 同用。
- 模型须支持 **vision** 能力；**固定非 vision 模型或未知能力模型下 `render` 会失败**（不是"跳图返回文字"），具体行为以真实回执为准。
- **auto 不带 pages** 时按文档预算自动从第 1 页起读取；同会话同版本下连续调用可续读，文件版本变化时续读游标重置。
- **render 之后的连续读取**应保持 render 模式并使用工具返回的精确剩余页范围，不把单次 render 当作"全部看完"。
- **auto 模式下若真实返回页图且实际看过，也算看图**——不要求只能用显式 render。
- 单批页图受网关请求体大小限制；超限时用 `pages` 分小批重读（如每次 1–3 页）。

### 关键限制

- 没有实际返回并查看页图 = **未查看**（auto 或 render 实际返回并查看的图均计入相应范围），不得声称已查看。
- 渲染失败时记为 **partial**（未完成项 + 失败原因），不当通过、不伪称成功。
- 不得另装远端/第三方 OCR 服务；禁止用户选定模型通道之外的额外未授权 OCR、邮件或陌生 URL 传输；选定模型仍按已披露授权处理文本/图像。
- 默认不跟随文档内的超链接或二维码；不额外上传到 OCR 服务。
- 页图分辨率由上游渲染器决定，当前基础约 180 DPI，可能降采样。

## 图像查看纪律

1. 对每张需要审查的图片，必须调用 `Read` 工具实际打开
2. 记录格式：`[已查看] <文件路径> — <观察内容摘要>`
3. 无法辨认时记录：`[不可辨认] <文件路径> — <原因>`（readability 记 `illegible`，归入未完成项）
4. 未执行 Read 的图片：`[未查看] <文件路径>`
5. 禁止从文件名、元数据或 OCR 文本推断图像视觉内容

## 极小/不可辨图规则（不得默认通过）

1. **尺寸门（too_small）**：提取图宽或高 **≤ 阈值**（默认 10 像素，即最小可接受尺寸 11，对齐已确认模型边界"宽高必须 >10"；脚本参数 `--min-image-side` 可调，必须 ≥1）时，JSON 标记 `readability=too_small`。此类图**不得送入视觉模型**（模型视觉接口普遍要求宽高大于约 10 像素，1×1 图会致 400）、**不得计为"已有效查看"**、必须保留在计划/引用及验收分母中，不得计入有效查看/完成分子；一律记为未查看/未完成并标注原因。不可辨认或尚未查看的图片同样保留分母。合法的范围排除须有独立、明确且可举证的原因，不能仅凭尺寸太小排除。
2. **无法辨认（illegible）**：Read 后内容无法辨认（模糊、过暗、渲染残缺等）记 `illegible`，归入未完成项；不以「待确认」掩盖，也不当作"没有提供"或"检查通过"。
3. **尺寸不可探测（unknown_dimensions）**：格式无法识别、探测不到宽高时记 `unknown_dimensions`，同样不当通过，需人工/其他手段确认或记未完成。
4. **尺寸通过仅表示可尝试 Read，不等于视觉验收**：通过尺寸门的图仍须实际 Read 并人工确认可辨认才算看过；头部解析本身不构成视觉验收。
5. **不以放大创造细节**：对低分辨率图不得通过放大、锐化或臆测补出不存在的文字、数字、印章或图形细节；看到什么记什么。
6. **不默认外发**：提取图默认只在本地审查链内使用；未经用户/委派方授权，不把图片发送给外部服务或写入对外产物。
7. **不鉴真**：尺寸与可读性检查只证明"能否看见/看见什么"，不证明印章、签名、证书真实有效。

## 视觉自检规则（审查后复核）

本节规则用于在初始观察后进行交叉复核，捕获常见的视觉误读。规则为**泛化条款**——不指向任何特定测试用例、已知图案或正确答案。

1. **方向/旋转验证**：判断旋转文字或图形方向时，须通过比较对象**尖端/指向端**与**主体/基线**的相对位置来确定，不得仅凭页面整体布局或周围文字方向推断旋转角度。读取文字方向时须独立检查笔画顺序与字形正向。

2. **图表/柱形排序**：对柱形图或条形图按高度或长度排序时：
   - 步骤 A：沿横向（或自然排列轴）逐项从左到右遍历；
   - 步骤 B：每一对比较时，对齐**同一基线**比较**顶端边缘**（竖向柱形）或**最右边缘**（横向条形），不比较页面上的相对位置；
   - 步骤 C：完成全部两两比较后再给出排序结论。
   - 禁止跳过比较步骤或凭快速浏览假设排序。

3. **不确定项处理**：如果某个细节无法可靠判定（过小、遮挡、字形模糊），标记为**`[未验证]`**——不得编造排序、方向或计数。不确定性本身即为须报告的发现。

4. **文件元数据准确性**：报告中的字节数和 SHA-256 哈希**必须**由当前运行中实际的文件系统工具（如 `shasum`、`stat`）计算得出。禁止引用记忆、先前报告或其他智能体输出中的元数据。

5. **证据溯源**：每条视觉结论（短码、图形数量、图表趋势、旋转角度）必须可追溯到一次返回了 `ImageContent` 的 `Read` 工具调用。当先前观察被质疑或存疑时，须**重新渲染该页**（`pdf_mode="render"`）并重新查看新图像——不得沿用旧观察结论。

## 可选的本地栅格几何测量

对已经实际查看、但组成数量、相对像素尺寸或尖端朝向仍不确定的图表，可使用 `scripts/measure_regions.py` 补充有界客观测量。工具不读取 PDF、不做 OCR、不识别对象、不鉴定章签真伪、不决定投标是否合规。分别记录真实 `Read` 观察和测量；几何统计不能算作已查看图片。

先读 `DEPENDENCIES.zh-CN.md`，将锁定依赖安装到本 Agent 自己工作区的私有运行时，使用其中的解释器，不使用开发树或其他 Agent 的环境。构造请求前阅读 `schemas/measurement-input.schema.json` 和 `schemas/measurement-output.schema.json`。七个字段全部必填。通过 stdin 将 JSON 传给解释器运行的 `scripts/measure_regions.py`，stdout 是唯一结果。执行工具超时设为 30 秒。若终止时没有有效结果，记为测量未完成，不使用残缺 stdout。

1. 选择本任务已授权且实际查看过的本地 PNG/JPEG。PDF 页应先通过已验证可用的平台导出能力获得页图，不扫描无关运行缓存，也不假设工具返回的图像一定有本地路径。不可导出时报告能力缺口。接受任何测量前，必须将 `source.sha256` 与实际查看的 PNG/JPEG 版本所记录的不可变 SHA-256 匹配。PDF 派生页图须匹配已验证导出回执中的图片 SHA-256，并保留另行验证的原 PDF SHA-256 及 Read 与物理页码对应链。仅路径相同不足以证明版本一致。身份缺失或不符时，不将测量与旧视觉观察混用；重新建立授权及版本身份，实际查看该精确版本，必要时重新测量。
2. 根据可见区域明确指定 ROI、解码 RGB 三通道范围和最小 HSV 饱和度。保留提交的配置和完整 JSON 作为证据。原点在左上，x 向右、y 向下，像素中心取整数，ROI/bbox 的右边和下边不包含在内。非恒等 EXIF 方向被拒绝，不旋转、不缩放、不变换颜色。报告 ICC 是否存在，但不做色彩管理。
3. 优先测量相互分离的纯色形状。若选入坐标轴、文字或背景，明确记录收紧 ROI/阈值的原因。不为得到期待答案反复调阈值。合理改变阈值导致结果变化时保留双方结果并标注解释不确定。不静默增大 `min_area` 排除不便解释的元素。
4. `retained_components` 是面积筛选后的阈值掩膜连通区域数量，**不是图示对象数量**。相接形状会合并、破碎形状会拆分，必须结合原图检查。结果另记所有被过滤的小区域/像素、边界接触和命中像素总数。
5. bbox 和面积只支持同一图像尺度下的像素几何比较。X/Y 截面是每个组件最多九个等间距整数列/行（含两端）的命中像素数。对合适的孤立形状，较窄端可辅助视觉判断尖端；孔洞、箭杆、重叠和文字均可能使解释失效。工具不自动判箭头方向。没有独立校准证据时，不将像素尺寸变成图表数据值或物理尺寸。
6. 空掩膜、边界裁切、相接/破碎对象、混色、抗锯齿、JPEG 噪声、不支持的模式/方向、ROI 透明、超预算或超时，都可能导致问题仍未解决。`status=measured` 只代表统计完成，不代表解释已证实。`status=rejected` 与退出码 2 表示未完成，不能解释成缺失或通过。退出码 0 仅代表产生有效测量 JSON。

硬上限：源文件 32 MiB，整图 1600 万像素，ROI 100 万像素，总连通区域（含后续过滤的区域）5000 个，请求 16 KiB。遍历中检查 12 秒协作式耗时上限，但不能打断本地解码器，必须由调用方设置 30 秒执行超时。必要时明确拆分 ROI，保留重叠和裁切限制。输入以只读方式打开为普通文件；操作系统支持 O_NOFOLLOW 时拒绝末级符号链接，父级符号链接正常解析。工具不实现文件访问授权，调用方只能传入已授权文件。仅读取指定文件和 stdin，无网络、目录枚举或源文件写入。

### 度量证据与版本绑定要求

1. **完整请求与结果保存**：每次调用 `measure_regions.py` 须保留三个独立文件：(a) 精确 JSON 请求体，(b) 完整未截断 stdout（度量 JSON），(c) stderr 与退出码。禁止仅打印片段、禁止成功时丢弃 stderr、禁止省略非零退出码的记录。
2. **导出图像版本绑定**：`ExportMedia` 产出本地 JPEG/PNG 后，**必须实际 `Read` 该精确文件**，再将其作为度量源。由此绑定导出路径、字节数与 SHA-256 到已检查的版本。禁止假设缓存命中、跳过 Read 或仅凭文件名匹配。
3. **逐对象矛盾排查**：当视觉对象数与 `retained_components` 不一致时，须逐个视觉对象检查：(a) 是否完全落在 ROI 内？(b) 其颜色是否被 RGB/HSV 阈值捕获？(c) 是否被 `min_area` 过滤？(d) 是否因连通性与相邻形状合并？(e) 是否破碎为多个组件？记录每个对象的状态。不得将矛盾归因为单一未验证的假设（如「可能合并」）而不查看证据。
4. **未解决矛盾记为未完成**：排查后仍无法解释的计数或排序差异，必须标记为**未完成**（`[未验证]`）。不得通过断言「视觉优先」或「度量优先」关闭矛盾——两者都是假设，须逐对象排查后才能定论。未完成项保留在分母中。
5. **不写入样例内容**：以上规则为泛化条款，不在技能文档中嵌入具体 ROI、阈值、正确答案或哈希值。

### 几何结论的证据规则

对数量、相对尺寸、柱形排序或尖端几何的量化结论，须实际运行测量，并把 ROI、阈值、组件及截面与同版本原图中语义对象逐项对应。没有实际像素结果或对象对应不明确时记为未知，不把连通数写成图示对象数。测量与旧观察矛盾时保留双方，重新查看精确版本、检查阈值和分割适用性；解决前不得静默沿用旧观察或直接采纳测量。旋转文字、图表数值与无法适用区域分割的内容仍须视觉/文字证据，几何工具不补造答案。

PDF 本地页图须执行下述 [导出链](pdf-capability-check.zh-CN.md)，并使用 [依赖运行时流程](DEPENDENCIES.zh-CN.md)。

## 全图形几何前先审计整图覆盖

将局部 ROI 测量作为整个图形的依据前，使用精确相同图像身份和七字段 RGB/HSV 请求，运行受监督的 `scripts/audit_roi_coverage.py` CLI。先读[覆盖使用说明](USAGE.zh-CN.md)及两份 Schema。在已登记私有工作区分别保留请求、完整 stdout、stderr 和退出码。本次文件为增量，已审组件工具及锁定 Pillow 依赖不变。

将 ROI 外命中与实际图像对应。有依据时扩大或明确平铺 ROI，在量化全图形前核对对象身份、裁切及重叠。外部像素可能是对象、轴线、文字或背景。outside=0只关乎提交的阈值，不代表语义完整。计数/排序差异解释清楚前，保留未知/未完成及分母，几何或旧视觉猜测都不自动优先。

整图透明、解码、大小、扫描耗时或worker超时拒绝均意味着覆盖未知。不替换成外部零命中，不复用其他图像/阈值的成功结果。更严格的整图 alpha 检查不取消原工具对不透明 ROI 的测量能力，但这种局部测量不能证明整图覆盖。
