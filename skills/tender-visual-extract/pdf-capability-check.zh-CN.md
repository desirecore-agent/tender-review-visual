# PDF 能力诚实说明

## 当前状态（2026-08-31）

直接使用现有工具处理任务材料。出现具体读取或渲染故障需要诊断时，检查工具参数并可选用小型无敏感样本；冒烟测试不是首次使用或任务准入要求，如实报告实际能力限制。

平台 PDF 读取工具（Read）支持两种模式：

| 模式 | 参数 | 行为 |
|------|------|------|
| 默认（auto） | 不传 `pdf_mode` 或 `pdf_mode="auto"` | 文字页抽取纯文本；扫描页/图像页自动渲染为页图；不带 `pages` 时按预算自动从第 1 页起读取 |
| 显式页图（render） | `pdf_mode="render"` + 显式 `pages` | 所有选页渲染为位图，用于查看配图、签章、图表、版式 |

## 能力边界

| 能力 | 状态 | 说明 |
|------|------|------|
| 文字页提取 | 已验证 | Read 默认模式直接读取文本层 |
| 页图渲染 | 已验证 | `pdf_mode="render"` + 显式 `pages`；模型须支持 vision |

> OCR 与文字层提取不同，是否可用以实际工具和处理结果为准。无需为普通视觉任务先做 OCR 冒烟。

## 使用约束

### 模型要求

- 页图模式需要模型支持 **vision** 能力。
- **固定非 vision 模型或未知能力模型下 `render` 会失败**，不是"跳图返回文字"。具体行为以真实回执为准——Smart 路由等受控 vision 选择须以实际返回结果确认。
- 实际渲染失败时可用单页诊断；正常任务直接处理分配材料。

### 页码与预算

- `render` 必须显式提供有效 `pages` 参数（如 `"1"`、`"1-3"`、`"1,3,5"`）。
- **auto 不带 `pages`** 时按文档预算自动从第 1 页起读取；同会话同版本下连续调用 `Read` 可续读，文件版本变化时续读游标重置。
- **render 之后的连续读取**应保持 render 模式并使用工具返回的精确剩余页范围，不把单次 render 当作"全部看完"。
- **auto 模式下若真实返回页图且实际看过，也算看图**——不要求只能用显式 render。
- 单批页图受网关请求体大小限制。超限时用 `pages` 分小批重读（如每次 1–3 页），后续批次自动收敛。

### 分辨率

- 页图分辨率由上游渲染器决定，当前基础约 **180 DPI**，可能降采样。
- 极低分辨率的嵌入图（如 ≤ 10×10 像素）在页图中可能仍不可辨认，需结合 DOCX 提取的原始文件判断。

## 失败时的记录策略

当 PDF 页图渲染失败时，必须：

1. **记录为未完成（partial）**：`[渲染失败] <文件> 第 N 页 — <错误信息>`
2. **不当作检查通过**：未渲染 ≠ 没有问题
3. **不伪称渲染成功**：不得从"未读到"推断"未提供"
4. **不用未渲染结果下结论**：不对未查看的图像内容做任何断言
5. **记录失败原因**：保留错误信息供后续排查

## 正确做法

- 文字页：正常提取文本，标记为 `[文字层已读]`
- 文字页配图/签章/图表：用 `pdf_mode="render"` 显式渲染后实际查看
- 图像页渲染成功：实际查看后记录观察内容
- 图像页渲染失败：标记 `[未完成-渲染失败]`，列入未完成清单
- 扫描页无法读取：标记 `[未完成-无法渲染]`，不得跳过
- auto 模式返回页图且实际看到：同样视为已查看，记录观察内容

## 禁止事项

- 不安装远端 OCR 服务
- 禁止用户选定模型通道之外的额外未授权 OCR、邮件或陌生 URL 传输；选定模型仍按已披露授权处理文本/图像
- 不因渲染失败而宣布"该页无问题"或"检查通过"
- 不用 OCR 文本替代对图像的实际视觉查看
- 不鉴定章签/证书真伪：视觉检查只报告可见性（有/无/模糊），不证明真实有效
- 不将标书内容（含提取图、人员信息、报价）发送至 OCR 服务、邮件或陌生 URL
- 与用户选定云模型的正常文本/图像处理通道须区分，不声称全程本地

## 与 DOCX 提取的区分

- DOCX 提取脚本（`extract_docx.py`）处理的是 ZIP 内部的 XML 结构和嵌入资源，**不依赖 PDF 渲染能力**。
- 有限 DOCX 提取不等于完整 Office 渲染：页眉、页脚、脚注、尾注、批注、嵌入式 OLE 对象等不在提取范围内。
- PDF 页图模式用于查看 PDF 文档的视觉呈现，与 DOCX 提取是独立能力。

## 云模型通道声明

使用用户选定的云模型时，发送的文本与图片会由该模型通道处理；不能承诺全程本地处理。


## 导出已查看的 PDF 页图进行本地几何测量

通过当前 ToolCatalog 核实 `ExportMedia`，参数严格为 `media_ref` 与 `file_path`；可用性取决于实际安装。该工具为 medium 风险、可回撤的**写入变更**，与只读 Read 分开，遵循平台真实审批策略。目标必须是已授权工作区内的新文件，父目录已存在；目标已存在时拒绝，绝不覆盖。不根据版本号或仅返回页图推断工具可用。

只使用当前 Read 页图结果或已授权附件真正提供的 `dc-media://` 引用。逐个绑定至当前原 PDF SHA-256、物理页码和实际查看图像的调用。不猜引用、不查看媒体缓存/令牌、不从诊断日志提取图片字节。多页渲染保留真实引用与页码对应；对应不明确时重读一个显式页码并验证。

调用 `ExportMedia(media_ref=<实际引用>, file_path=<已登记私有工作区内新路径>)`。成功返回 JSON 文本，字段为 `path`、`media_ref`、`mime_type`、`bytes` 和 `sha256`；原字节导出、不重新渲染或压缩，最多 32 MiB。工具**不返回** PDF hash 或页码，这两项须来自另行验证的原文件清单和 Read 对应关系，不编成导出字段。保留真实返回、审批结果和任何错误。写入失败、授权拒绝或能力缺失均记未完成。

即使 ExportMedia 支持更多媒体类型，几何工具只接收 PNG/JPEG。传入已授权的返回 `path`，要求 helper 的 `source.sha256`、`source.bytes` 分别等于导出的 `sha256`、`bytes`；按声明的不旋转坐标规范核对实际格式/尺寸。将导出 `media_ref` 匹配回实际查看的 Read 图像以及原 PDF hash/页码链。身份缺失或冲突须重新建立精确版本并实际查看，不能混入旧观察。导出成功不等于测量或视觉验收成功。
