# 整图 ROI 覆盖审计

此工具是 `measure_regions.py` 的配套工具，检查**同一解码 RGB/HSV 掩膜**是否在所选 ROI 外仍有像素。不识别对象、不计语义对象数量、不推图表值或投标结论。不增加包依赖，使用已安装且哈希锁定的 Pillow 12.3.0 / Python >=3.10 环境。将 `scripts/audit_roi_coverage.py` 放在原已审 `scripts/measure_regions.py` 同目录；后者提供七字段验证和原有限制，保持不变。

先读输入/输出 Draft-07 Schema。用该环境解释器运行脚本，把原七字段测量 JSON 通过 stdin 传入。在本 Agent 当前登记的私有工作区分别保存请求、完整 stdout、stderr 和真实退出码，不写未登记临时目录或发布源。CLI 自行监督派生 worker，调用工具另外设 24 秒超时。退出码0 / `audited` 仅表示掩膜审计完成；退出码2 / `rejected` 表示 `coverage=unknown`，不会编造部分计数。生产调用不得绕过受监督 CLI，直接调用内部 Python 函数。

输出精确源 SHA-256/字节数、尺寸/格式、配置、实际扫描像素数，以及整图/ROI内/ROI外命中像素数和 bbox。坐标沿用不旋转的左上原点、右下不包含约定，不缩放、不采样。为兼容保留请求 `min_area` 和 `connectivity`，但它们**不筛除覆盖像素**，工具也不计算组件。原组件工具的 100万像素 ROI 与5000组件上限不扩大。

用局部 ROI 支撑全图形几何陈述前，先执行覆盖审计：

1. 实际查看精确授权图像。PDF 页沿用已验证的 Read→ExportMedia→本地 Read 链，保留原 PDF hash/物理页对应及导出图像身份。将审计源 SHA/字节数与该链及随后组件测量比对，仅路径相同不够。
2. 用与组件测量一致的 RGB 范围、HSV 饱和度审计所选 ROI。RGB 上下界包含；S=(maxRGB-minRGB)/maxRGB，黑色S=0。不做 ICC/gamma 变换。
3. ROI 外有命中时，在实际图像中定位其 bbox。它可能是遗漏对象、轴线、文字或背景。逐个记录可见对象处于 ROI 内外及理由。按需扩大或明确平铺 ROI，仍遵守原100万像素限制，再测量并核对重叠/边界对象身份，不能将切开的或重叠对象重复计数。保留全部配置和审计结果。
4. 外部无命中仅说明**此阈值**未选中外部像素。异色、低饱和度、孔洞、裁切及未选中的对象仍须视觉核查。outside=0或连通数均不证明全图覆盖。无法解释的矛盾保留为未知/未完成并计入计划分母，不静默清零。
5. 整图任何位置出现有效透明都拒绝审计，包括 RGB/L PNG tRNS。这有意严于原 ROI 工具：后者可在外部透明时测量完全不透明的 ROI，但这种局部结果不能证明整图覆盖。不得合成背景或修改原图来制造通过；记录限制，使用有独立依据的视觉/人工证据。

资源上限：单个只读普通文件快照32 MiB、整图1600万像素、ROI仍最多100万像素、请求16 KiB。扫描每4096像素检查12秒耗时预算。另有独立spawn进程，父进程等待最多18秒，再最多两次各1秒清理join；本地解码挂起也返回rejected/unknown。启动/调度开销在该等待之外，因此调用方24秒上限仍有用。像素存储由输入/解码图像大小限制：有限个Pillow栅格缓冲和常数大小计数/bbox累加器，不保留逐像素Python对象或无界组件列表。这是算法资源边界，不是跨平台OS RSS配额。worker被OS终止意味着未知，不能写outside=0。

不写源文件。系统支持时末级路径使用O_NOFOLLOW，父级链接按调用方已授权路径解析。工具不实现授权、不扫描目录、不联网、不取凭据。超时时worker若来不及报告源身份，source可为null，不得猜测将失败绑定到其他图像。
